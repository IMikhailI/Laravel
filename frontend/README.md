## Описание

Frontend-приложение разработано на Vue 3 и предназначено для аутентификации пользователя через Laravel backend с использованием Bearer-токенов.

После успешной авторизации полученный токен сохраняется в localStorage и используется для выполнения защищённых запросов к API.

## Используемые технологии

- Vue 3
- Vite
- Pinia
- Axios
- Laravel API
- Laravel Sanctum
